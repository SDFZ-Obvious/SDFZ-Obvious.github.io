# MediaInsight 自媒体数据分析助手

同时支持 **哔哩哔哩** 与 **YouTube** 的账号流量监测、数据分析与运营建议工具（Windows 桌面程序）。

## 快速开始

直接双击 `dist/MediaInsight.exe`：

1. **B站扫码登录**：用手机 B 站 App 扫码，程序会自动抓取全部稿件（播放、点赞、投币、收藏、评论、分享、弹幕、标签、分区）、粉丝数、创作中心完播率和 30 日趋势。
2. **YouTube 登录**：选择 Google Cloud 下载的 OAuth `client_secret.json`（对话框内有 5 步说明），获取播放、观看时长、完播率、留存曲线、转粉/掉粉、流量来源、设备、年龄性别、地区等深度数据；或只填 API Key 查看公开数据。
3. **加载演示数据**：不登录也能体验全部功能。
4. 在 **设置 / 自动监控** 中填写刷新间隔，程序会定时抓取并积累历史快照（增长趋势、生命周期、转粉估算依赖快照）。

登录凭据与数据只保存在本机 `%APPDATA%\MediaInsight`，不会上传。

## 功能一览

| 页签 | 内容 |
|---|---|
| 总览 | 核心 KPI、健康度评分（增长/互动/稳定/留存/转粉/爆款 6 维）、行动清单 |
| 增长趋势 | 粉丝曲线 + 30 天预测、里程碑预计日期、每日播放与 7 日均线、每日涨掉粉 |
| 发布时间 | 星期 × 时段热力图、按小时/星期表现、**最佳投稿时间 Top3** |
| 时长分析 | 各时长区间的播放、**转粉率**、**3 秒跳出率**、完播率 |
| 互动分析 | 点赞/投币/收藏/评论/分享/弹幕率、三连率、币赞比、藏赞比、互动趋势 |
| 留存与跳出 | 留存曲线、最陡流失点、回看高峰、同时长完播率诊断、**稿件内容留存建议** |
| 内容与标题 | 分区/标签表现、标题关键词提升度、标题特征（数字/问句/括号…）、标题长度 |
| 爆款诊断 | 相对同期的表现倍数、爆款与低于预期稿件、爆款共同特征 |
| 粉丝转化 | 千次播放涨粉、转粉 Top10、互动与转粉关系、掉粉比 |
| 更新节奏 | 每周投稿数、稳定度、更新间隔对表现的影响 |
| 生命周期 | 发布后 1–14 天播放累积曲线、长尾常青稿件 |
| 流量与受众 | 流量来源、设备、年龄、性别、地区、粉丝/非粉丝占比 |
| 评论洞察 | 情感分布、高频词、**观众诉求（选题来源）**、负面反馈 |
| 竞品对比 | 添加同领域 B站 UID / YouTube 频道，对标粉丝、播放、互动、更新频率 |
| 发布模拟器 | 输入星期/时间/时长/类别/标题，预测播放区间并推荐更好的发布时段 |
| 视频明细 / 运营报告 | 可排序搜索的明细表；导出 **HTML 图文报告** 与 **Excel 明细** |

> “表现指数” = 稿件播放 ÷ 相邻发布稿件的中位播放，用来抵消账号成长和发布时间长短的影响，使新老稿件可比。

## 数据来源说明

- B站未开放 3 秒跳出率、单稿涨粉、受众画像等接口。可在创作中心导出稿件数据表格，用 **导入后台数据** 导入（自动识别“BV号/标题、完播率、3秒跳出率、涨粉、平均播放时长、曝光、点击率”等列）。未导入时，转粉数据会用粉丝快照估算并标注“估算”。
- YouTube 的 3 秒跳出率由 Analytics API 的留存曲线估算（官方不直接提供）；曝光量与点击率可从 YouTube Studio 导出后导入。
- 未登录时 B站部分接口会触发风控，程序会自动切换备用接口。

## 从源码构建

需要 Windows + Python 3.11 及以上版本：

```bat
build.bat
```

输出 `dist\MediaInsight.exe`。测试：`python tests\smoke_test.py`（分析 + 图表 + 报告）、`python tests\gui_test.py`（界面自动化截图）。

```
main.py     入口      MediaInsight.spec / build.bat（打包）
```
