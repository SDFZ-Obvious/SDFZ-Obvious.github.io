    How 2 Play?

  • Tap the desktop with your wrist

    ---Simulate the kick drum of a drum set

  • Tap the desktop with the pen tip

    ---Simulate the Close Hi-Hat of a drum set

  • Tap the desktop with the pen body

    ---Simulate the Snare of a drum set

  • Swipe the desktop with the pen tip

    ---Simulate the Open Hi-Hat of a drum set
